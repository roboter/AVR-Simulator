## ✨ Features

| Feature | Description |
|---|---|
| ⚡ **AVR Core Emulation** | Executes a wide set of AVR instruction set opcodes |
| 📄 **Intel HEX Parsing** | Load and run `.hex` files generated by AVR-GCC / avrdude |
| 🖥️ **WPF Interface** | Clean graphical interface for real-time visualization |
| 🔄 **Background Worker** | Non-blocking emulation keeps the UI responsive |

---

## 🔬 Supported AVR Chips

| Chip | Status |
|---|---|
| **ATmega328** | ✅ Fully supported |
| Other AVR chips | 🔧 Extensible via `AVRInterpreter` base class |

> 💡 The `AVRInterpreter` base class provides a solid foundation for implementing additional AVR chip variants.

## 🛠️ How to Build

### 📋 Prerequisites

- 🪟 **Windows OS**
- 🔵 **.NET 10 SDK** (LTS) or later
- 🏗️ **Visual Studio 2022+** (or `dotnet` CLI)

---

### 🖱️ Building with Visual Studio

1. Open `AVR Simulator.sln` in **Visual Studio**
2. Select the **`Release`** configuration
3. Click **Build → Build Solution** (or press `Ctrl+Shift+B`)
4. The executable will be at:
   ```
   bin/x86/Release/net10.0-windows/AVR Simulator.exe
   ```

---

### ⌨️ Building with the dotnet CLI

1. Make sure the [.NET 10 SDK](https://dotnet.microsoft.com/download) is installed
2. Navigate to the project root directory
3. Run:
   ```bash
   dotnet build -c Release
   ```
4. The executable will be at:
   ```
   bin/x86/Release/net10.0-windows/AVR Simulator.exe
   ```

---

## 🚀 Usage

> By default, the simulator loads **`Blink.hex`** from the execution directory.

A sample `Blink.c` / `Blink.hex` is included in the repository so you can get started immediately.

**Quick start with the dotnet CLI:**
```bash
dotnet run
```

To load a custom file, edit [`MainWindow.xaml.cs`](MainWindow.xaml.cs) to change the hardcoded path or wire up a file picker dialog.
